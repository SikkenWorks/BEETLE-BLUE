# BEETLE BLUE V1.0.0 RC1 — verification report

**Scope:** software-only Release Candidate. The original V0.99.8 package/source supplied by the user is the baseline; previous functionality is preserved unless explicitly stated.

## Confirmed source fixes

1. **Setlist with no saved projects:** V0.99.8 used SEL to create P01 even when that project did not exist, then HOME attempted to save invalid entries. V1.0 RC1 gives HOME priority over other keys, permits only verified stored project slots, never inserts on an empty-slot scan, and preserves the previous nested HOME route. A failed setlist save remains marked unsaved and can be retried. A deliberate subsequent HOME leaves without falsely claiming successful persistence.
2. **Song Chain range paste:** original implementation wrote over the cursor row. The new clipboard pastes *after* the cursor, shifts existing rows without overwriting, preserves all six independent lane references and repeats, checks capacity before mutation, and preserves the original source clipboard.
3. **Legacy build:** non-BLUE PCM build wrongly accessed an edition-only `track_drum_voice.reverse`. The non-BLUE branch now uses forward ROM traversal as before; BLUE reverse remains enabled.
4. **PCM test fixture:** checksum `dd0f3681` was independently measured on the unmodified V0.99.8 baseline and the new code, and the legacy test updated accordingly. This change is not a sound-engine alteration.

## Explicitly NOT proven

- Complete FM1 power-loss / backup / recovery route, safe flashing and OTA rollback.
- 30+ minute heavy playback involving all six drums, samples, effects, USB and rapid project loads, with no `DMA DEADLINE` / `AUDIO STOP`.
- Physical DAC safe peak gain, headset protection, streaming stability, precise synchronization and battery charge indications.
- Exhaustive absence of overlapping text on **all** FM1 pages under arbitrary names/values. Only included native C snapshots were visually checked.

**Release gate:** label as RC1 experimental for controlled bench tests. Do not declare production-safe V1.0 until all device acceptance criteria pass.
