## Functional distinctions / unresolved Release Candidate gates
- The native dry-path bypasses the new FX loops; effect memory is fixed 36 bytes. No callback malloc or flash IO added by step FX.
- **Delay/reverb/chorus** in BEETLE PCM are short *ROM-tap* effects; in MONOLITH they are tonal/modulation approximations. They are not equivalent to a conventional buffered echo/reverb/chorus.
- Storage V2 streamed WAVs have no PCM random-access history; REV and history-based delay/reverb/chorus do not yet operate on those streams. Other waveform dynamics use the shared path; physical output remains unverified.
- **Not completed:** physical DMA DEADLINE reproduction/resolution, peak-level measurements on analogue outputs, verified flash/recovery, USB stems, flash wear/endurance, complete hardware UI interaction testing.
- Read-only diagnostic build was not completed as part of this V0.97 release. Native production build and host tests passed; don't substitute this for hardware validation.
- **Classification:** experimental V0.97, **not** V1.0 RC-certified, and **not** hardware-safe-to-flash-certified.
