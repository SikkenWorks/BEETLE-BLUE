# BEETLE BLUE V0.99.6 Live Mode validation

## Source changes

- Native FM1 startup offers NEW PROJECT / LOAD PROJECT / LIVE MODE.
- Live Mode has Setlist, Perform, and a modal stop-choice screen; all are real FM1 LCD C code.
- Setlists contain 24 ordered references to the existing 12 project slots, allowing repeated songs.
- Projects are loaded from the existing CRC-checked journal only in the foreground, after audio stops.
- Playback of a Song Chain ends at its last position in Live Mode even when its stored LOOP is ON. Project's saved LOOP remains unchanged; original flag is restored on exit.
- SONG OFF plays one pattern cycle. Next project is loaded and left READY until a new PLAY press.
- Manual PLAY stop opens Continue Current Track / Start Current Track Again. The former resumes the current step/song position, the latter restarts at the first song position.
- Setlist SAVE uses an independent 64-byte record with CRC32 inside the Storage V2 B2SB metadata A/B indices (offset 2610); does not touch the BDR1 V31 project serialization or 12 project slots.
- Non-V2 storage fails the SAVE operation explicitly, without writing to unowned flash.

## Not yet verified / warnings

No physical M-VAVE FM1 was available here. Actual display, input scan timing, persistent flash safety, power-loss reliability, true transition latency, live audio stability and project-specific BPM behavior have **not** been physically verified. V0.99.4 showed real hardware DMA deadline failures, and V0.99.5 was not proven to resolve them. This release is **experimental**, not stage-approved. Back up all projects and user samples, and establish independent recovery before flashing.

Audio stop/resume is step-based rather than sample-position-accurate. Long sample tails or Punch-In states may not resume from their previous internal PCM sample position after a manual stop. A sample-accurate pause/resume feature needs further hardware-focused work.
