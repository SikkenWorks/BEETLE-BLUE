## Known limits / hardware-critical gates

- **No physical FM1 flashed or exercised here.** DMA DEADLINE, audio stops, analog clipping, long concurrent Storage V2 streaming, flash/XIP contention, USB audio, power-failure recovery and OTA reliability remain unverified.
- Cached attacks cover **256 frames at 22050 Hz (about 11.6 ms)**. Long sample tails still need background flash fetches. First hit before idle warming finishes may still wait for prefetch. Full sample residency would require more RAM than these caches provide.
- Warm cached samples are decoded from the original *lossy 4-bit BD4S format*, not bit-identical to WAV input or the factory PCM-ROM; audio quality depends on original transcoding.
- User sample streaming still does not implement full REV/history-tap FX or global Punch PITCH as on factory ROM voices. This release optimizes attack timing only, not full engine feature parity.
- Hardware validation must demonstrate a minimum 30-minute stress run with all 13 sample slots, dense 6-lane retriggers, playback, LCD, FX, and USB interactions without DMA DEADLINE; also require waveform/audio peak measurements.
- This build is **EXPERIMENTAL**, not a validated V1.0 release candidate. Back up storage, confirm independent recovery path, and avoid using irreplaceable projects on a test device.
