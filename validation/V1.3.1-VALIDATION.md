# BEETLE BLUE V1.3.1 — UC25HQ80 compatibility validation

## Scope

- V1.3.1, package identity `FM-1_2224` (unchanged), target M-VAVE FM1.
- Added explicit `FL_JEDEC_OK` for Puya P25Q80 `0x856014` and UCUN UC25HQ80 `0xB36014` in both application flash driver and rebuilt RAM OTA loader.
- Unknown JEDEC IDs cause the erase/program drivers to return `-5` **before Write Enable**, with the SPI/SFC state restored; read-only access remains possible.
- Generic 1 MiB flash commands, Storage V2, `BDR1 V33`, mixer, Live Mode and user kits unchanged.
- The inherited SPL and first 16 KiB of `flash.bin` are **identical** to V1.3. The `ota.bin` RAM loader changes intentionally, compiled from pinned GPL Felucca source and now included in the source tree.
- Official stock-V15 acceptance source, OTA priority over project transfer and bounded 900-second timeout unchanged.

## Important updater distinction

The new loader is bundled in the **incoming** V1.3.1 firmware. An already running older firmware with a loader that refuses `0xB36014` cannot be fixed from within that older loader merely by publishing a new package. Recover through the device-supported ROM/download path first and then install V1.3.1. Never blindly overwrite the bootloader.
