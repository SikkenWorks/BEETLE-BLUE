# BEETLE BLUE V1.0 Release Candidate gates

Software readiness alone is not sufficient for an RC.

- [x] Native build with preserved header and OTA-loader and app integrity checks
- [x] PCM output buffer cleared before drum mixing (V0.94)
- [x] 14 BEETLE drums / 16 MONOLITH procedural models pass host audio tests
- [x] Native REV step selection and per-hit PCM reverse on BEETLE and local one-shots (V0.95)
- [x] Pattern FX identifier fits V30 wire format; host serialization tested
- [ ] FM1 hardware repeated-kick DMA DEADLINE reproduction and demonstrated resolution
- [ ] Safe analogue levels at maximum polyphony measured on hardware
- [ ] Verified real-device flash and independently tested recovery route
- [ ] Project and sample flash journal long-run/power-interruption tests on target
- [ ] Global BBK1 kit-bank independent backup/restore
- [ ] Storage V2 streamed WAV reverse semantics or explicit disabled control
- [ ] True PCM-time-reversal for MONOLITH, or final specification explicitly calls out reverse-style synth variant
- [ ] WebSimulator step FX model aligned with native UI and audible results
- [ ] USB six-stem capture host/device timing tested
- [ ] Final synth-code dependency and RAM/CPU audit, no unsafe removals
- [ ] Pixel-accurate LCD overflow audit, all screens and overlays on device
- [ ] RC acceptance run after all fixes, documenting exact target hardware and firmware hashes

Until all critical on-device gates pass, label builds **experimental**, never verified RC.
