# BEETLE BLUE V1.0 RC12 — Release Status

- **Release status:** V1.0 RC12 is a published BEETLE BLUE release.
- **Firmware package:** A complete RC12 `.fwsc` firmware container has been released, including the firmware and OTA updater. The separate `.fwsc.lab` is a development artifact and must not be confused with the released `.fwsc`.
- **WebInstaller / Manager:** RC12 versions are included in the release and replace the earlier RC11-only tools. Use the RC12 tools when installing RC12.
- **On-device HELP:** 10 topics, 66 short two-line cards and up to 3 separated cards per screen. K2 selects the topic; K1 changes the page; HOME and SEQ retain their navigation functions.
- **Project format:** BDR1 V33, unchanged from RC11. Storage, drum kits, audio engine and Live Mode data paths are unchanged.
- **Hardware testing:** BEETLE BLUE has been extensively tested by its developer on **two physical M-VAVE FM1 units**. This statement does not independently certify every RC12 installation, OTA recovery scenario or firmware-package validation test.
- **Documentation:** README is the current user guide only. Version history and bug fixes belong in CHANGELOG. Historical validation material remains archived.
